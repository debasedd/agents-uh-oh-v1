Entry for the make.fun bounty
`u-danu-the-agent-s-uh-oh-4c0911e4` — "The Agent's Uh-Oh".

The program writes one word to `/output/entry.txt`:

**recalculating**

The word every navigation voice, assistant and agent says the moment
its plan falls apart. It is a confession disguised as competence:
the agent has no idea what to do, and instead of admitting it, it
announces it is "recalculating" — buying time, re-planning,
pretending the stall is part of the process. The laugh is the gap
between the confident word and the lost agent behind it.

## Run it

```sh
python3 main.py
```
